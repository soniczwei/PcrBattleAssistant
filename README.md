# PcrBattleAssistant

**日本語** | [简体中文](README.zh-CN.md)

『プリンセスコネクト！Re:Dive』（DMM版）向けのアリーナ編成検索・戦績登録補助デスクトップアプリです。[pcrdfans.com/battle](https://www.pcrdfans.com/battle) を内蔵し、ゲーム画面のメモリキャプチャからキャラアイコンを自動認識してWeb側へ自動入力します。

## 技術スタック

- **フレームワーク**: C# / WPF（.NET 11 / `net11.0-windows`）
- **MVVM**: `CommunityToolkit.Mvvm`
- **内蔵ブラウザ**: `Microsoft.Web.WebView2`
- **画像認識**: `OpenCvSharp4`
- **ウィンドウ取得**: Win32 API `[LibraryImport]`（`PrintWindow` / `BitBlt`）

## 対応範囲・主な機能

> **認識対応画面（限定）**：本ツールは以下の画面のみ認識に対応しています。
> - **バトルアリーナ**：対戦相手リスト（右側 3 編成）および「対戦履歴詳細」
> - **プリンセスアリーナ**：「対戦履歴詳細」（3v3・3 編成）

- **ワンクリック検索（スキャン / 戦績登録統合）**: `PrincessConnectReDive.exe` の画面をメモリ取得し、シーンを自動判別します。
  - 「編成検索」タブでは右側の防衛編成を自動入力して検索します（3v3 は 1〜3 隊を一括入力）。上部の防衛カードをクリックして編成を切り替えられます。
  - 「戦績登録」タブ（または対戦履歴詳細スキャン後に各行右端の「登録」ボタンをクリック）では、左右の攻撃・防衛編成を同時に認識して自動入力します。3v3 では行ごとに「登録」を押して連続投稿でき、中央の `VS` 下の入れ替えボタンで攻防を反転できます。
- **信頼優先表示**: いいね済み／自分が投稿した編成を現在の検索結果ページの上位に優先表示するオプションに対応。
- **キャラアイコン更新**: 起動時の自動チェックおよび「キャラ更新」ボタンで、変更時のみスプライト画像を再取得・ローカル分割します。
- **デバッグモード / 多言語 UI / 更新確認**: 解析エリア・一致率の表示、**日本語 / 简体中文 / English** の即時切り替え、起動時の GitHub Releases バージョン確認に対応。

## 使い方

1. **編成検索**: 「編成検索」タブで、ゲーム内のバトルアリーナ相手一覧または 3v3 対戦履歴詳細を開き、上部の **スキャン** をクリックします。
2. **戦績登録**: 「戦績登録」タブで（または対戦履歴詳細をスキャン後、上部各パーティ行右端の **登録** ボタンから）攻撃・防衛編成を自動入力して投稿します。

## 安全性について

- **ゲームメモリ・通信は一切読み書きしません**: Windows 標準 API によるウィンドウ画像取得とローカル OpenCV マッチングのみを行い、プロセス注入・メモリ改変・通信傍受・ゲーム自動操作機能は一切含みません。
- **ローカル完結**: 取得画像はメモリ内のみで処理され外部へ送信されません。WebView2 のログイン情報も端末ローカルにのみ保存されます。
- **通信先**: 本サイト（`pcrdfans.com`）の表示、キャラ画像更新（`peterli110/pcrdfans_statics`）、およびアプリ更新確認（GitHub Releases API）以外への通信は行いません。
