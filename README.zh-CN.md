# PcrBattleAssistant

[日本語](README.md) | **简体中文**

《公主连结 Re:Dive》（DMM版）竞技场查作业与战绩上传辅助桌面工具，内嵌 [pcrdfans.com/battle](https://www.pcrdfans.com/battle)，支持内存截图识图并自动向网页填入阵容。

## 技术框架

- **框架**：C# / WPF（.NET 11 / `net11.0-windows`）
- **MVVM**：`CommunityToolkit.Mvvm`
- **浏览器**：`Microsoft.Web.WebView2`
- **图像识别**：`OpenCvSharp4`
- **窗口截图**：Win32 API `[LibraryImport]`（`PrintWindow` / `BitBlt`）

## 支持范围与主要功能

> **识别范围说明**：本工具**仅支持**识别以下游戏界面：
> - **バトルアリーナ**：对手选择列表（右侧 3 阵容）及「対戦履歴詳細」
> - **プリンセスアリーナ**：「対戦履歴詳細」（3v3 三队阵容）

- **一键扫描（查作业 / 战绩上传合一）**：截取 `PrincessConnectReDive.exe` 窗口到内存并自动识别场景。
  - 在「作业查询」Tab：自动识别右侧防守阵容并填入查询（3v3 自动填入 1~3 队），点击顶部防守卡片可快速切换。
  - 在「战绩上传」Tab（或扫描对战履历详情后点击每行末的「上传」按钮）：同时识别左右进攻与防守阵容并自动填入上传页，3v3 可逐队点击「上传」连续提交；点击中间 `VS` 下方的互换按钮可反转攻防。
- **信任置顶**：支持将点赞过或自己上传的作业优先置顶显示在当前查询结果页最前。
- **角色自动更新**：启动时后台比对远程雪碧图版本，有变化时才下载并在本地切割更新；也可点击「更新角色」手动检查。
- **调试模式 / 多语言 / 更新检查**：支持查看分析区间与匹配度，支持 **简体中文 / 日本語 / English** 实时切换，启动时自动检查 GitHub Releases 新版本。

## 操作说明

1. **查作业**：在「作业查询」Tab 下，游戏内打开バトルアリーナ对手列表或 3v3 対戦履歴詳細，点击顶部 **扫描**。
2. **战绩上传**：在「战绩上传」Tab 下，游戏内打开対戦履歴詳細，点击顶部 **扫描**（或直接点击顶部队伍行末的 **上传** 按钮）。

## 安全与免责说明

- **不读写游戏内存与封包**：仅通过 Windows 标准截图接口读取画面并在本地完成 OpenCV 匹配，不注入进程、不修改内存、不拦截通信，无任何自动点击游戏功能；截图仅存内存不上传，登录凭据由本地 WebView2 独立保存。
- **网络通信说明**：除内嵌展示 `pcrdfans.com`、更新角色雪碧图（`peterli110/pcrdfans_statics`）及启动时检查应用版本（GitHub Releases API）外，不向其他任何外部地址发送请求。
